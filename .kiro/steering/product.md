# Product Overview

## Game Parkour 2D - Mê Cung Phiêu Lưu

A 2D platformer action-adventure game developed in C++ using WinBGIM graphics library. Players navigate through multi-level labyrinths, collecting keys, battling enemies, and finding exits.

### Core Gameplay
- **Genre**: Platformer 2D with parkour mechanics, combat, and puzzle elements
- **Objective**: Collect 3 golden keys, defeat enemies, and reach the exit door
- **Mechanics**: Physics-based movement (gravity, friction, jumping), shooting system with normal bullets and rocket jumps, enemy AI with patrol and shooting behaviors

### Target Audience
Educational project for C/C++ programming courses, demonstrating:
- Graphics programming fundamentals
- Game development concepts (game loop, collision detection, state management)
- Algorithm implementation (Bresenham line/circle, Midpoint algorithms, Flood fill)
- Data structures and physics simulation

### Academic Requirements
This project fulfills requirements for:
- **TP2**: Custom implementation of line/circle drawing algorithms (Bresenham/Midpoint) and polygon fill algorithms
- **TP3**: Fractal geometry integration (Koch curves, Dragon curves) as environmental decorations
- **TP4**: 2D transformations (translation, rotation, scaling) for character movement and animations

### Current Status
Multi-level game with 5 levels, each featuring unique layouts, enemy configurations, and increasing difficulty. Includes menu system, pause functionality, HP system with invincibility frames, and level progression.
